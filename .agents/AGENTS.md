# Workspace Rules

- Always provide the clickable local link [http://localhost:8000](http://localhost:8000) to open the page in every response.
- Never compress, optimize, downscale, or reduce the quality of any image in the project under any circumstances. Always preserve images at their original, uncompressed full resolution.
- Always make code modular: keep CSS, JavaScript, components, and data organized into clean, dedicated, maintainable modules rather than monolithic files.
